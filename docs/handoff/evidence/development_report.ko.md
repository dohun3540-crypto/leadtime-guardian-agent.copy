검증 계층의 합성 테스트는 PO·품목·원래 납기·수량 충돌, 누락 날짜, 잘못된 단위·화폐, 중복 문서·통보, 모호한 입고, 견적 공급량/업체 충돌, NaN 가격, 미완료 작업 응답, 최상위 검토 필요 신호, 손상된 JSON 보관·차단을 확인했다. 기존 C1/C3 계산 회귀 테스트도 통과했다. 실제 PDF 기반 C2 근거 검증을 완료한 것으로 표시하지 않았다.

실패 및 수정 기록:

1. 로컬 최초 테스트 수집은 패키지 미설치로 실패했다. `PYTHONPATH=src`로 현재 소스를 사용해 해결했다.
2. 파일 보관 테스트 1개가 Windows 임시 폴더 생성 문제로 준비 단계에서 실패했다. 작업 폴더 안의 새 `--basetemp`를 지정한 재실행에서 48개 모두 통과했다.
3. 첫 GitHub CI는 Ruff 0.17.3의 표기 검사 2건으로 실패했고 pytest는 실행되지 않았다. 불필요한 suppression 제거 및 UTC 표기 변경 후 다음 CI에서 Ruff와 테스트 48개가 통과했다.
4. API 실행기 추가 후 첫 CI도 Ruff의 예외 처리 규칙 2건으로 실패해 pytest는 생략됐다. 타입 오류는 TypeError로, 수송 오류는 명시적인 SDK/API 오류 유형으로 처리하도록 수정했다. 다음 CI에서 61개 테스트와 Ruff가 통과했다.

## C. 미완료 및 정확한 제한

- 사용자가 열어 둔 Workflow 1의 실제 노드·프롬프트·필드 확인, 저장, 업로드, 실행은 완료하지 못했다. 워크플로우 이름도 변경하지 않았다.
- 최신 직접 접속 주소는 `https://studio.upstage.ai/agents/agt_bXRXFSAqFmBayPjZF7VgRQ`이며, 제어 가능한 같은 앱 내 브라우저에서 404를 반환했다. 워크플로우 부재와 현재 계정 권한 문제 중 원인은 확정하지 못했다. 최신 증거는 `studio-workflow-404-latest.png`다.
- Studio 로그인 버튼은 Google 계정 인증으로 이동했다. 자동 승인 검토가 별도 Google 인증 접근 권한이 없다는 이유로 차단했다. 인증 정보 입력·인증 우회는 수행하지 않았다.
- 사용자가 별도 브라우저에서 직접 로그인하겠다고 응답했다. 마지막 주소 확인 시 해당 탭은 여전히 Google 로그인 화면이었다. 이미 로그인한 Chrome의 계정 상태와 별도 브라우저의 상태는 다르다.
- `studio_prompt_spec.DESIGN_ONLY.json`은 적용 전 설계다. 실제 Studio 설정 Export가 아니다.
- 공식 Agents API 응답 envelope 처리는 합성 계약 테스트다. 실제 UI export 포맷 및 API 수송은 아직 실실행으로 검증하지 않았다.
- API 실행 코드는 구현했지만, 현재 로컬 환경에 UPSTAGE_API_KEY와 선택 SDK가 없어 실호출하지 않았다. 사전 검사와 자격증명 부재 시 중단 경로만 직접 실행했다. `api_preflight.NOT_STUDIO.json`, `api_prerequisites_blocked.NOT_STUDIO.json`에 네트워크 요청 0건을 기록했다.
- 추가한 importer는 C001의 단일 입고/견적 구조를 우선 검증한다. 여러 입고를 합산한 PO 행의 수량 연결 등은 실제 예측 구조 확인 후 명시적인 Adapter 규격을 확장해야 한다.
- `evidence_verified_against_pdf=false`를 유지한다. PDF 생성 확인 또는 정규화 값의 일치는 실제 예측값의 원문 근거 검증을 뜻하지 않는다.
- C001 실실행 성공 전이므로 20케이스/60PDF 확장, 성능 평가, native export, 실제 시연 영상 및 제출은 진행하지 않았다.

## D. 필요한 사용자 작업과 재개 지점

같은 Work 앱 내 브라우저 세션에서 해당 Agent의 편집 화면에 실제 접근할 수 있어야 한다. 주소는 확보했으므로 같은 주소를 다시 보낼 필요는 없다. 계정 또는 워크스페이스의 접근 상태를 확인해야 한다. API 대안은 로컬 환경에 자격증명과 선택 SDK를 설정한 후 사용할 수 있지만, 검증되지 않은 workflow 설정이 자동 완성되는 것은 아니다. 비밀번호·API 키를 채팅으로 보낼 필요는 없다.

PDF와 정답 후보의 최종 사람 검수는 별도 필요하다. 실제 발주·메일 발송·LMS 최종 제출은 수행하지 않았다.
